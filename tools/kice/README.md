# 교육부 기본 어휘 3,000 (교재 검사기 전용)

`tools/check.js`가 교재 단어가 한국 공교육 기본 어휘에 있는지 확인할 때만 읽는 파일입니다.
앱은 이 파일을 불러오지 않습니다.

## 출처

- 교육부(2022). 영어과 교육과정. 교육부 고시 제2022-33호 [별책 14] [별표 3] 기본 어휘 목록
- 받은 곳: 한국교육과정평가원 「KICE Word Lister」 안내서 PDF (경기도교육청 공개, 2023-06), 인쇄 쪽 5~34
- 고시는 저작권법 제7조에 따라 보호받지 않는 저작물입니다. 안내서의 다른 부분(프로그램 설명 등)은 가져오지 않았습니다.

## 파일

| 파일 | 내용 |
|---|---|
| kice-basic-3000.csv | 단어, 단계(tier), 다른 표기(alts), 파생형(family), 원문(raw) |
| extract.py | PDF에서 목록을 뽑는 스크립트 (`python3 extract.py <PDF>`, pdfplumber 필요) |

tier: 1 = `*` 초등 권장 800개, 2 = `**` 중고 공통 권장 1,200개, 3 = 그 외 1,000개

## 검증

- 총 3,000개, tier 800 / 1,200 / 1,000: 교육과정 지침의 숫자와 일치 (스크립트가 다르면 실패)
- 모든 대표 단어가 PDF 본문에 있음, 중복 없음
- 원문 순서 그대로 (modify 다음 model 은 원문의 순서)
- 같은 PDF로 다시 실행하면 CSV가 한 글자도 다르지 않음

## 쓰는 법 (검사기)

대표형 + 굴절형(wrote, books) + 지침의 파생 접사형(-ly, -ness, -er 등)을 같은 단어군으로 봅니다.
입문(L1), 초급(L2) 유닛의 단어가 목록 밖이면 참고로 알려 줍니다. 병원, 약국처럼 상황에 꼭 필요한 단어는 목록 밖이어도 괜찮습니다.
